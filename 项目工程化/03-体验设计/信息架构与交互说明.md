# 信息架构与交互说明

## 页面层级

```text
认证页
└── 招工工作台
    ├── 智能问答
    │   ├── 初始欢迎语
    │   ├── 快捷提问
    │   ├── 多轮消息
    │   └── 参考来源
    └── 浏览岗位
        ├── 工作地区筛选
        ├── 岗位类型筛选
        └── 岗位详情卡片
```

## 首屏原则

- 首屏只回答三个问题：这是什么、我现在能做什么、系统是否可用。
- 主路径是“问需求 → 筛岗位 → 看详情”，不把管理信息放在主内容区抢占注意力。
- 状态和错误要可操作：告诉用户是模型、索引还是数据问题。
- 重要信息使用明确文本，不依赖颜色单独传达含义。

## 关键交互

| 场景 | 行为 | 反馈 |
|---|---|---|
| 快捷提问 | 点击问题写入待发送输入 | 问题进入问答流程 |
| 空问题 | 不调用模型 | 保持输入框可用 |
| 超长问题 | 拒绝并提示长度限制 | 不写入会话 |
| 无来源回答 | 转人工提示 | 不伪造岗位事实 |
| 模型不可用 | 页面继续可浏览岗位 | 侧栏展示启动/模型提示 |

## 无障碍与响应式

- 控件保留可见文本和焦点状态。
- 移动端隐藏非必要装饰，流程卡片改为单列。
- 颜色对比度优先于装饰，按钮文字必须在浅色和深色背景上可读。
