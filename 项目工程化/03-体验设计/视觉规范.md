# 视觉规范

## 设计方向

以“本地招聘工作台”为主题：深青色表达可靠和本地服务，黄橙色作为岗位数据和行动提示，浅色背景保持长时间使用的舒适度。

## 颜色令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `--deep` | `#10383A` | 品牌侧栏、主视觉 |
| `--ink` | `#183236` | 正文和标题 |
| `--jade` | `#087F73` | 成功状态、链接、强调 |
| `--sun` | `#F4C95D` | 指标规则、提醒 |
| `--coral` | `#EF8F6B` | 数据装饰、警示辅助 |
| `--paper` | `#F7FBF9` | 页面背景 |
| `--line` | `#D5E4DF` | 分隔线和边框 |

## 组件原则

- 卡片圆角不超过 8px，避免套娃式容器。
- 信息卡先显示结论，再显示解释。
- 岗位卡统一显示工厂、职位、地点、班次、工资、要求、福利。
- 状态文字同时配合语义文本，不只使用颜色。
