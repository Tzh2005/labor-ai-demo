# 发布前检查清单

> 每次发布复制一份，勾选项必须附证据或备注。未勾选项不等于通过。

## 变更与产品

- [ ] 版本号、目标环境和发布负责人已确定。
- [ ] 需求、验收标准和不做范围已评审。
- [ ] 用户可见文案、岗位数据和 FAQ 已确认来源与时效。
- [ ] 变更影响（功能、数据、模型、依赖、隐私）已分级。

## 代码与依赖

- [ ] `git status --short` 无未解释改动。
- [ ] 已记录 Git SHA，并检查 `git diff --check`。
- [ ] `python -m py_compile app.py ai_service.py knowledge_base.py conversation_store.py` 通过。
- [ ] `python -m pytest -q` 通过，失败项已获得明确豁免。
- [ ] `requirements.txt` 的变化已说明；没有把 `.env`、密钥、数据库、向量库和虚拟环境打包。

## 数据与模型

- [ ] `data/jobs.json`、`data/faq.md` 已校验格式、编码和更新时间。
- [ ] SQLite 数据库已备份并可读取。
- [ ] Chroma 索引是否重建已决定；需要重建时已预估时间和磁盘。
- [ ] `OLLAMA_MODEL`、模型文件和嵌入模型版本已记录。
- [ ] 任何数据迁移都有向前/回滚步骤。

## 安全与配置

- [ ] `DEMO_PASSWORD` 使用部署环境注入的随机长密码，不写入仓库或日志。
- [ ] `OLLAMA_BASE_URL` 仍为允许的本机地址，未引入未经评审的外部端点。
- [ ] 生产日志不会打印密码、完整用户隐私或模型密钥。
- [ ] 防火墙只开放必要端口；公网访问优先经过 HTTPS 反向代理。

## 验收与运维

- [ ] 健康检查通过：Streamlit、Ollama、配置模型。
- [ ] 关键路径冒烟：岗位检索、FAQ、来源展示、多轮追问、人工转接。
- [ ] 已记录首字/全文响应时间和错误信息。
- [ ] 备份、日志、监控和告警联系人已确认。
- [ ] 回滚包、回滚命令和恢复后的验收步骤已准备。
