# 用户反馈闭环

## 反馈分类

| 类型 | 示例 | 默认优先级 |
|---|---|---:|
| 事实错误 | 工资、地点、福利回答与岗位资料不符 | P0/P1 |
| 找不到 | 已有岗位未被检索召回 | P1 |
| 体验问题 | 输入、筛选、移动端显示异常 | P2 |
| 数据缺失 | 岗位信息过期或字段不全 | P1 |
| 新需求 | 收藏、推荐、微信渠道 | P2/P3 |

## 闭环字段

每条反馈至少记录：反馈时间、匿名场景、原问题、展示回答、来源、数据版本、严重级别、负责人、修复版本和验证结果。不要记录身份证、完整手机号或无关聊天内容。

## 处理状态

`新建 → 已分级 → 修复中 → 待验证 → 已关闭`。

P0事实错误或隐私问题先下线相关数据/功能，再讨论长期修复；不得等待完整迭代周期。
