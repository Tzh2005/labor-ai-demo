# 质量门禁

## 提交门禁

- Python 语法检查通过。
- 单元/安全回归测试通过。
- 依赖检查通过，没有把本地数据库、索引、密钥加入提交。
- 变更包含对应文档和测试证据。

## 发布门禁

- P0/P1缺陷为零，或有技术负责人书面豁免。
- 核心问答、追问、岗位筛选、模型不可用四条路径完成验收。
- 评估集版本、模型版本和数据签名已记录。
- 备份和回滚步骤已在目标环境验证。
- 生产配置使用强密码，未使用示例值。

## RAG质量门禁

在没有实际评估结果前，不得宣称准确率、Faithfulness、Answer Relevancy 或成本节省百分比。每次检索算法变更至少比较：

- 召回覆盖率（问题所需事实是否进入上下文）。
- 来源覆盖率（回答是否能指向来源）。
- 事实性人工抽检。
- 首字延迟、全文延迟和P95。

## 失败处理

任一门禁失败时，停止发布，记录失败证据，修复后重新运行全套检查；不得只重跑失败项后直接上线。
